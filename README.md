# my-startup-landing
나의 첫 번째 실습

## ① 창업 아이디어 한 장
| 항목 | 답 |
|---|---|
| **서비스 이름(가칭)** | 루트메이트 (Routemate) |
| **서비스 사용자** | 친구·연인과 데이트나 나들이를 계획하는 20대 수도권 사용자 |
| **해결할 문제** | 장소 정보가 여러 플랫폼에 흩어져 있어 탐색에 시간이 오래 걸리고, 동행인의 취향과 이동 동선을 고려해 코스를 짜기 어렵다. |
| **해결 방법** | AI가 사용자의 취향·방문 목적·지역·시간을 고려해 맞춤 코스를 추천하고, 동행인과 장소를 공유·수정·투표하며 함께 최종 루트를 완성한다. |
| **한 줄 소개** | **AI가 추천하고, 우리가 함께 완성하는 하루의 루트.** |

## ② 서비스의 핵심 사용 흐름
1. 조건 입력 (지역·취향·시간)
2. AI 코스 추천 (장소·동선 제안)
3. 함께 완성 (공유·수정·확정)

## ③ Copilot Spaces에서 대화 시작하기
나는 **Routemate(루트메이트)**라는 AI 기반 공동 일정·동선 설계 서비스를 기획하고 있어.

**핵심 서비스 개념**
- 타깃: 친구·연인과 데이트나 나들이를 계획하는 20대
- 문제: 여러 플랫폼에 흩어진 장소 정보를 찾아보고, 서로의 취향과 이동 동선을 고려해 일정을 짜는 과정이 번거로움
- 해결: AI가 취향·지역·시간에 맞는 코스를 추천하고, 동행인과 함께 장소를 수정·추가하여 최종 루트를 완성

이 서비스를 소개하고 사용자의 관심을 유도하는 모바일 중심 랜딩 페이지를 기획하고 싶어.

먼저 다음 내용을 제안해줘.

1. 사용자에게 가장 설득력 있는 핵심 가치 제안
2. 첫 화면의 헤드라인과 서브카피
3. 문제 제기 → 해결 방식 → 핵심 기능 → CTA 순서의 랜딩 페이지 구성
4. 핵심 기능 3가지와 사용 시나리오
5. 서비스에 대한 관심을 검증할 수 있는 CTA

기능을 많이 나열하기보다는 사용자가 겪는 문제와 해결 가치를 직관적으로 전달하는 데 집중해줘.
